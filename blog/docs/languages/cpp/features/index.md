## 版本速查

- C++11：
    - `auto`：根据初始化表达式推导变量类型。
    - Lambda：在表达式中定义可捕获上下文的匿名函数。
    - 移动语义：转移对象资源，减少不必要的深拷贝。
    - `constexpr`：允许函数和变量参与编译期计算。
    - 可变参数模板：使模板能接收任意数量和类型的参数。
    - 智能指针：通过 RAII 自动管理动态资源的所有权。
    - 线程库：提供线程、互斥量、原子操作和异步任务。
    - `std::array`：封装固定长度数组，并提供标准容器接口。
    - `std::tuple`：在一个对象中存储多个不同类型的值。
    - `std::chrono`：统一表示时钟、时间点和时长。
    - `<random>`：将随机数引擎与概率分布分离。
- C++14：
    - 泛型 Lambda：允许 Lambda 形参使用 `auto` 推导类型。
    - 初始化捕获：在 Lambda 捕获列表中创建并初始化新成员。
    - 返回类型推导：使用 `auto` 或 `decltype(auto)` 推导函数返回类型。
    - 变量模板：定义可按模板实参实例化的变量。
    - `std::make_unique`：构造对象并安全地返回 `unique_ptr`。
    - `std::integer_sequence`：在编译期表示整数序列。
    - `std::exchange`：替换对象的值并返回旧值。
- C++17：
    - 结构化绑定：将数组、聚合或 tuple-like 对象解构为多个名称。
    - `if constexpr`：根据编译期条件丢弃不适用的分支。
    - 折叠表达式：用指定运算符简洁地展开参数包。
    - CTAD：根据构造函数实参推导类模板实参。
    - inline 变量：允许在头文件中定义共享的变量实体。
    - `std::optional`：表示可能存在，也可能缺失的值。
    - `std::variant`：在有限类型集合中安全地存储其中一种值。
    - `std::any`：存储任意可拷贝类型的单个值。
    - `std::string_view`：以非拥有视图读取连续字符数据。
    - `std::filesystem`：提供路径、目录和文件状态操作。
- C++20：
    - concepts：为模板实参声明可读、可组合的约束。
    - ranges：使算法直接作用于范围，并支持惰性视图管道。
    - `<=>`：统一表达对象的三路比较关系。
    - 协程：通过 `co_await`、`co_yield` 和 `co_return` 支持可暂停函数。
    - 模块：提供独立于文本包含的代码组织与导入机制。
    - `consteval`：要求函数调用在编译期完成求值。
    - `std::span`：以非拥有视图访问连续元素序列。
    - `std::format`：使用类型安全的占位符语法格式化文本。
    - `std::jthread`：在析构时请求停止并自动等待线程结束。
    - `std::source_location`：在默认参数中捕获调用处的源码位置。
    - `std::bit_cast`：在等长且满足条件的类型之间安全复制对象表示。
- C++23：
    - 显式对象参数：显式声明成员函数的当前对象参数。
    - `if consteval`：区分函数当前是否处于编译期求值。
    - 多维下标：允许 `operator[]` 接收多个索引参数。
    - static 调用运算符：使无状态函数对象不需要隐式对象参数。
    - `std::expected`：显式表示成功值或错误值。
    - `std::print`：使用 `std::format` 语法直接输出格式化文本。
    - `std::generator`：基于协程惰性产生元素序列。
    - `std::mdspan`：以非拥有视图访问多维数据。
    - Ranges 增强：增加分块、滑动窗口、组合遍历和范围转换等工具。

## 编译与特性检测

### 编译器支持与选项

选择语言标准时，需要同时设置编译选项并确认编译器与标准库的实现情况：

- GCC 和 Clang：使用 `-std=c++11`、`-std=c++14`、`-std=c++17`、`-std=c++20` 或 `-std=c++23`
- MSVC：使用 `/std:c++14`、`/std:c++17`、`/std:c++20` 或 `/std:c++latest`

例如：

```bash
g++ -std=c++20 main.cpp -o main
clang++ -std=c++20 main.cpp -o main
cl /std:c++20 main.cpp
```

!!! warning "实现进度"

    语言标准已经发布，不代表所有编译器和标准库都已完整实现。
    使用 C++20 和 C++23 特性前，应检查目标工具链的支持情况。
    对兼容性要求较高的项目，还应结合特性测试宏进行判断。

### 语言标准检测

可以通过 `__cplusplus` 判断当前语言标准：

```cpp
#if __cplusplus >= 202302L
// C++23
#elif __cplusplus >= 202002L
// C++20
#elif __cplusplus >= 201703L
// C++17
#endif
```

### 特性测试宏

检查某项特性时，优先使用标准定义的特性测试宏：

```cpp
#include <version>

#if defined(__cpp_lib_format) && __cpp_lib_format >= 201907L
#include <format>
#endif
```
